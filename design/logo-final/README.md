# Duplex Logo Final (03 Direction)

This package refines concept `03` into production-ready assets.

## SVG assets

- `duplex-icon-03-final.svg`
  - Square icon for app icon and favicon generation.
- `duplex-lockup-horizontal.svg`
  - Icon + wordmark, horizontal orientation.
- `duplex-lockup-stacked.svg`
  - Icon + centered wordmark.

Packaging exports now live under `build/icons/`.

## Color tokens

- Background dark: `#091423`, `#0E1E31`
- Structure stroke: `#1D2A3A`
- Primary accent: `#22D3EE` to `#14B8A6`
- Secondary accent: `#93C5FD` to `#5EEAD4`

## Font recommendation

Wordmark target typeface: **Space Grotesk** (fallbacks included in SVG text).
Convert text to outlines if you need exact cross-platform shape locking.
